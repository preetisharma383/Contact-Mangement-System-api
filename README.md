# 📇 Contact Management System (MERN)

A full-stack **Contact Management Application** built using the **MERN stack**.  
Users can securely **create, view, update, and delete contacts** with authentication and authorization.

---

## 🚀 Features

- 🔐 User Authentication (JWT based)
- ➕ Add new contacts
- ✏️ Edit existing contacts
- 🗑️ Delete contacts with confirmation
- 📄 View all contacts in a data table
- 🔍 Fetch contact by ID
- 👤 User-specific data (ownership based)
- ⚡ Fast UI with React & DataTables
- 🛡️ Secure API with protected routes

---

## 🛠️ Tech Stack

### Frontend
- React.js
- React Router DOM
- Axios
- React Data Table Component
- SweetAlert2
- React Icons

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
